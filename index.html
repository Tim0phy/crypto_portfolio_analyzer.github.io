為什麼用 Crypto Portfolio Analyzer？

專為 Binance 交易紀錄設計，計算方法透明、可覆核。

多檔案拖放匯入

一次拖入多個 Binance CSV，自動合併、去重並按時間排序。

準確持倉計算

將每筆 Change 加總，與交易所真實餘額對齊，手續費、空投與獎勵全部計入。

成本基礎配對

同一秒內的 Buy 與 Spend 自動配對並按比例分攤成本，避免第三方工具誤判 Launchpool 等交易。

實時市價與圖表

CoinGecko 現價，配合成本基礎 vs 市值增長圖與持倉分佈圖，走勢一目了然。

已實現盈虧與年度總結

以 FIFO 計算每次賣出的已實現盈虧，並按年份分組，方便報稅參考。

私隱至上，無需註冊

全部在本機瀏覽器運算，不上傳任何資料；結果存入本機儲存，下次自動還原。

三步開始

從 Binance 匯出到完整分析，只需幾分鐘。

1

匯出交易紀錄

在 Binance「訂單 → 資產記錄 → 交易記錄」匯出 CSV 檔案。

2

拖入瀏覽器

把 CSV 拖到上傳區，多個檔案會自動合併與去重。

3

即時查看分析

持倉、成本基礎、盈虧與圖表即刻生成，全部本地計算。

你的資料，留在你的裝置

除了向 CoinGecko 查詢公開幣價外，此工具不會把任何資料發送到伺服器。你的交易紀錄只會在瀏覽器本機處理，並儲存在本機儲存（localStorage），不會上傳。

持倉分佈（按市值）

說明：持倉數量 = 該幣種所有紀錄變動量加總（含買入、賣出、手續費、空投、獎勵等），與交易所實際餘額應一致。 成本基礎採用時間排序的 FIFO 帳本：同一秒內的 Transaction Buy 與穩定幣 Transaction Spend 互相配對，賣出、提幣或幣幣轉換會扣減剩餘成本； 穩定幣存款視為現金本金，成本基礎為面額；非穩定幣單純存入或空投因無對應花費，成本基礎計為 0。已實現盈虧以 FIFO 淨收入減去被消耗批次的成本計算；第三幣手續費按該幣 FIFO 成本扣除。 重複上載完全相同的檔案會被自動偵測並略過（採用整份檔案內容比對，而非逐行比對，避免誤刪真實但欄位數值相同的交易，例如同一秒內執行的多筆定投）。 若市價更新失敗且該幣種沒有任何先前成功抓取的快取價格，畫面會以 ⚠ 標示並顯示「(N/A)」，代表該筆市值暫時以 $0 計算，並非真實市值。 此工具所有計算均在您的瀏覽器本機完成，不會上傳任何資料到伺服器；分析結果會儲存在本機瀏覽器（localStorage）方便下次開啟直接查看。
